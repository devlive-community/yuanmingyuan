# ADR-0002 · 中式殿宇的围护形式按类型分四种

- 状态：已采纳（阶段 4）
- 日期：2026-10-22

## 背景

此前生成器只有台基、柱网、斗拱、屋顶，所有中式殿宇在页面上都像敞亭。逐栋的门窗装修记载
（样式雷装修图、档案）目前没有整理，但 60 余栋建筑需要统一补上墙与门窗。

## 决策

1. 建筑参数增加 `enclosure`（`open` / `front` / `surround` / `gate`，缺省 `front`）与
   `corridor`（`none` / `surround`），由 `blender/generator/carpentry.py` 生成檐枋、墙、槛框与扇。
2. 类型按清官式通例套用（见 speculative S-042）：亭、敞阁 `open`；殿堂斋轩楼 `front`；榭、水中殿宇 `surround`；
   宫门、山门、天王殿 `gate`。每栋 YAML 中显式写出非缺省值并注明理由。
3. 新构件按材质类分网格：`beams`、`red_wall`、`wall_base`、`joinery`、`paper`（标签末段 = 材质类，沿用现有约定）。
4. 比例常量放 `units.py`；纹样、扇数等细节为模块内工作假设。

## 后果

- 拿到某栋的样式雷装修图后，只需改该栋 YAML（或新增纹样参数），不用改其他建筑。
- 外观接近清官式通例，但不是逐栋复原：页面详情的「围护」一行与 S-042 说明这一点。
