# ADR-0003 · 海晏堂另做「参考图效果版」，与史料复原版并存

- 状态：已采纳
- 日期：2026-10-22

## 背景

用户提供了一张写实的海晏堂效果图（AI 生成），要求网页达到「和截图一样」的效果。该图与史料有直接冲突：
米白石材墙（史料：粉红色灰墙）、灰瓦（史料：孔雀绿琉璃瓦）、圆/椭圆池（史料：菱形池）、
生肖铜像立于池内两列（史料：沿八字墙两列）、满墙卷涡雕饰（铜版画远较简洁）。
项目约定历史真实优先，取舍须由用户决定；用户选择「两版都做，页面可切换」。

## 决策

1. 史料复原版 `haiyantang`（western.py，S-023）保持不变，仍为景区目录中的默认版本。
2. 新增 `haiyantang_reference`（blender/generator/haiyantang_reference.py、data/scenes/haiyantang_reference.yaml）：
   - 正楼、石跑梯、导水台、蓄水楼、南北喷水池复用史料版几何，只改材质类（`walls` / `marble` → `limestone`，琉璃 → `roof`）；
   - 楼前改为参考图式椭圆池、全铜袍服生肖坐像、池心假山群像喷泉、贝壳卷涡雕饰、檐上瓶饰与立像、乔木柏树。
3. 页面：该版本不单列于景区目录、不进总图；在海晏堂信息卡上以「史料复原 / 参考图效果」切换，
   参考图版标签固定显示「参考图效果 · 非史料复原」。
4. 参考图版的内容不登记为推测复原项（它不是复原），其与史料的差异写在场景 YAML 头注释中（页面「景区说明」可见）。

## 后果

- 渲染管线（实拍材质、烘焙、喷泉粒子、天空）的改进对两版同时生效；参考图版用来追观感，史料版用来追真实。
- 只做海晏堂；其他景区不做参考图版，除非用户另有要求。
