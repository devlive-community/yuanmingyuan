# 史料清单与置信度规则

本文件登记项目引用的史料、其用于哪些参数，以及置信度。新增引用时按同一格式追加。

## 置信度定义

| 等级 | 含义 |
|---|---|
| high | 有明确文献条文、图档或实测数据直接支持，数值可复核 |
| medium | 有文献原则性依据，具体数值为学界通行归纳（如梁思成《清式营造则例》的比例表），不同实例存在差异 |
| low | 无直接史料，依同类建筑类比或工程常识推测，须在 `docs/speculative.md` 登记 |
| placeholder | 占位示例数据，尚未接入真实史料，**不得用于最终复原** |
